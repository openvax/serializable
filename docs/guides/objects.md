# Save existing classes and files

## Constructor-based classes

Inherit from `Serializable` when you already have a normal constructor. Store
an attribute for each constructor argument, or implement `to_dict()` with keys
that the constructor accepts.

```python
from serializable import Serializable

class Sample(Serializable):
    def __init__(self, name, count):
        self.name = name
        self.count = count

sample = Sample("tumor", 3)
restored = Sample.from_json(sample.to_json())
print(restored.name, restored.count)
```

```text
tumor 3
```

The base class supplies equality and a representation from the stored fields.
For dataclasses, use the [dataclass mixin](../index.md#save-and-reload-an-object)
to retain the methods generated by the dataclass decorator.

## Save JSON to a file

Continuing the preceding example, use the constructor-based class's file
helpers. This example uses a temporary directory so it does not overwrite an
existing file.

```python
from pathlib import Path
from tempfile import TemporaryDirectory

with TemporaryDirectory() as directory:
    path = Path(directory) / "sample.json"
    sample.write_json_file(path)
    restored = Sample.read_json_file(path)
    print(restored == sample)
```

```text
True
```

`DataclassSerializable` provides JSON string methods, without the file helpers.
For a dataclass, write `object.to_json()` with `Path.write_text()` and reload
the text with `YourClass.from_json()`.

## Nested objects and collections

Module-level helpers serialize supported containers as well as individual
objects. Continuing with `sample` from above:

```python
from serializable import from_json, to_json

restored = from_json(to_json({"samples": [sample]}))
print(restored["samples"][0].name)
```

```text
tumor
```

Keep each object's class importable when loading it in another process. A
notebook or a script's local class is a convenient demonstration; a class in
an importable module is preferable for persisted data shared across programs.
